# البصمة والإضافي — دليل مبرمج

المادة 107: الأجر الإضافي يُستحق **عن ساعات العمل الإضافية** — أجر الساعة + 50%، أو إجازة تعويضية **بموافقة العامل**.

القاعدة: **بصمة الانصراف تثبت البقاء، لا أنّ العمل أُمر به وأُدّي.**
فالساعات تُسجَّل من البصمة، لكن الحكم عليها قرار مدير مُسبَّب — لا نتيجة حسابية.

---

| **107/3** | «جميع ساعات العمل **التي تُؤدَّى** في أيام العطل والأعياد» |

| | *(النسخة السارية M/46 من 25/3/2015؛ وكانت إحدى عشرة قبلها — الكتالوج يحمل الاثنتين مؤرَّختين)* |
| **102** | «**لا تدخل** الفترات المخصصة للراحة والصلاة والطعام **ضمن ساعات العمل الفعلية**، ولا يكون العامل خلالها **تحت سلطة صاحب العمل**» |

لو كان البقاء = عمل، لما احتاج المشرّع المادة 102.

## الفكرة

```
يوم أُغلق ببصمتي حضور وانصراف:
  اشتقّ الدقائق الزائدة            → autoOvertime.deriveAutoOvertimeCore
  افتح قيداً واحداً بانتظار القرار  → otDecisionPlan.stampActualOvertime
      source: "actual_punch"
      workedProven: true            ← البصمة أثبتت البقاء

قرار المدير — ثلاثة لا اثنان:
  صرف            أجر الساعة + 50%                     (107/1)
  إجازة تعويضية  بموافقة العامل + موعد تمتّع           (107/1 + اللائحة 22 مكرر)
  رفض مُسبَّب     سبب مكتوب لا يقل عن ثلاثة أحرف        (البقاء ≠ عمل)

الساعات تبقى في السجل في الحالات الثلاث.
مسار العامل للاعتراض: طلب «تصحيح انصراف» في طلباتي.
```

**الصرف يبقى الأصل.** الرفض استثناء يُسجَّل باسم من قرّره وبسببه — لا سكوت ولا خصم صامت.

---

## ما الذي تغيّر

كان القفل في الواجهة يمنع الرفض منعاً مطلقاً متى صارت `workedProven` صحيحة:

```js
// قبل — attendanceDerivations.js
if (decision === "reject" && input.workedProven === true) {
  return { ok: false, error: "OT_WORKED_NO_REJECT", … };
}
```

فموظف نسي بصمة الانصراف الساعة 5:00 وبصم 7:00 كان يُلزم المنشأة بساعتين لم تُعملا، والمدير لا يملك أن يقول «لم يُعمل». صار الشرط سبباً مكتوباً:

```js
// بعد
if (decision === "reject" && input.workedProven === true) {
  const note = String(input.note || "").trim();
  if (note.length < 3) return { ok: false, error: "OT_REJECT_REASON", … };
}
```

> ملاحظة: `base44/shared/attendanceDerivations.ts` لم يحمل هذا القفل أصلاً — كان الخادم يسمح بالرفض والواجهة تمنعه. التعديل وحّد الجهتين.

## حدود لا تُمسّ

- الساعات **لا تُحذف** من السجل مهما كان القرار — التدقيق يقرأ `otDecisions`.
- الإجازة التعويضية **لا تكون بلا موافقة مسجّلة** (`COMP_LEAVE_CONSENT`)، وموعد التمتّع داخل نافذة اللائحة 22 مكرر.
- سقف 720 ساعة في السنة وموافقة العامل على تجاوزه (`OT_ANNUAL_CAP`) — كما هو.
- يوم العطلة الرسمية ويوم الراحة الأسبوعية: كل دقيقة عُملت إضافي (107/3 و104) — كما هو.
- اليوم المخطط على الجدول بلا بصمات يبقى «مخطط»، لا يُصرف قبل أن يُعمل (`OT_NOT_WORKED_YET`).
