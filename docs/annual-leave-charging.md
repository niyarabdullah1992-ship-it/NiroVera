# حسبة الإجازة السنوية — دليل مبرمج

المادة 109: الرصيد **21 يوم عمل** (30 بعد خمس سنوات).  
الطلب يختار مدى تقويم (`startDate`–`endDate`). الرقم الذي يُخصم **ليس** عدد أيام التقويم.

القاعدة: **يوم الدوام لذلك الموظف يُخصم. يوم الراحة له لا يُخصم.**  
نفس الدالة تعمل لدوام خمسة أيام، ستة أيام، وأربعة/أربعة.

---

## الفكرة

```
لكل يوم في المدى:
  عطلة رسمية (عيد / وطني / تأسيس)     → 0
  هذا الموظف مسند على وردية في الجدول → 1   حتى لو جمعة أو سبت
  خلية راحة له على الجدول (قريب منه إسناد) → 0   أربعة/أربعة هنا
  وإلا: راحة 104 أو راحة الشركة حسب الملف → 0
  غير ذلك → 1
```

المصدر الأول **الجدول المنشور لذلك الشخص** (`company.schedules` + `stationId`).  
الجمعة/السبت احتياط فقط إن لم يُرسم له جدول قريب.

لا تدمج الأنظمة في `if (fourOnFour) … else if (fiveDay)`.  
ارسم الراحة على الجدول؛ الحسبة تقرأ الخلية.

## أين الكود

| ماذا | أين |
|---|---|
| عدّ أيام السنوية | `chargeableAnnualWorkDays` في `src/lib/leaveEidOverlap.js` |
| duty / rest / unknown | `employeeRosterDayKind` نفس الملف |
| واجهة الطلب | `chargeableLeaveDays(..., type, calendar, company, employee)` في `leaveDerivations.js` |
| حفظ الطلب | `submitLeaveRequest` في `store.js` — للسنوية استخدم الناتج المشتق لا `requestedDays` التقويمي |
| عرض «محسوب» | `RequestsWorkspace.jsx` → `counted` |

مرضّية: `chargeableSpanExcludingHolidays` (تقويم ناقص عطلاً رسمية فقط).  
حج: أيام تقويم بما فيها العيد.

مرّر **دائماً** `company` و`employee` (لا الملف وحده إن وُجد الجدول).

## قراءة الجدول

```
schedule = schedules.find(s => s.stationId === workStationId || stationId)
assignments["YYYY-MM-DD"][shiftTypeId] includes employee.id  → duty
لا إسناد + له إسناد خلال ±7 أيام                                 → rest   (دورة 4/4)
لا جدول قريب                                                     → unknown → weekdays
```

`workStationId` في الملف يغلب `stationId`. لا تخلط فروع الجداول.

أربعة/أربعة = نوع `12 بقاء` (`07:00–19:00` أو ليلي 12 ساعة) أربعة خلايا ثم أربع فارغة.  
`isTwelveStayDuty` / `checkFourOnFourDutyPattern` في `shiftWeek.js` لمنع النشر ورمضان، **ليست** مدخل حسبة السنوية.

## يوم أو يومان راحة أسبوعية (غير 4/4)

احتياط عندما `employeeRosterDayKind === "unknown"`:

1. `weeklyRestDow` (افتراضي 5 = الجمعة) — المادة 104.  
2. `weeklyRestDayCount` منشأة: 1 أو 2. الثاني = اليوم التالي (سبت إن كانت الجمعة).  
3. ملف الموظف `profile.weeklyRestDayCount`: فارغ = يتبع المنشأة؛ `1` ستة دوام؛ `2` خمسة دوام.

إن وُجدت خلية **duty** يوم السبت لعامل 4/4 أو تغطية — **يُخصم**. الجدول يغلب يوم الشركة.

## أمثلة اختبار

نفس الطلب: `startDate`–`endDate` طولها يومان تقويم.

| مدى | خمسة أيام (جمعة+سبت راحة، بلا جدول 4/4) | أربعة/أربعة (أحد–أربعاء دوام، خميس–أحد راحة) |
|---|---|---|
| أحد–اثنين | 2 | 2 |
| أربعاء–خميس | 2 | 1 |
| خميس–جمعة | 1 | 0 إن كانا راحة الدورة |
| دورة 8 أيام كاملة | — | **4** لا 8 |
| سبت عليه وردية 12 بقاء | 0 عادة | **1** |

ليل 12 بقاء (`19:00–07:00`) لا يغيّر العدّ: الخلية دوام أو راحة. 18632 على الإسناد والنشر لا على الرصيد.

رمضان: 4/4 تبقى 12 بقاء (`ramadanUsesDailySixCap` = false). حسبة السنوية لا تنزل الرصيد إلى 6.

## قواعد عند الكتابة

1. لا `days = end - start + 1` للسنوية.  
2. لا تفترض أن الجمعة راحة لكل موظف.  
3. لا تحسب نقص تغطية (خلية وردية بلا أحد) غياباً ولا سنوية على شخص غير مسند إلا إن كانت راحته في الدورة.  
4. أرقام الشاشة مشتقة. بعد الاعتماد أعد العدّ من التواريخ + الجدول، أو خزن `days` كناتج `chargeableAnnualWorkDays` فقط.  
5. عزل `companyId`. جدول الفرع فقط.

دوال البداية: `employeeRosterDayKind` → `chargeableAnnualWorkDays` → `chargeableLeaveDays`.
