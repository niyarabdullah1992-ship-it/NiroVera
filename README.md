# نيروفيرا NiroVera

منصّة موارد بشرية سعودية لا تكتفي بتسجيل العمل، بل **تُثبت أنّه أُنجز**:
الحضور ← المهمّة ← المراجعة ← التصعيد ← التوقيع ← إثبات للعميل.

## بنية المستودع

| المجلد / الملف | ما فيه |
| --- | --- |
| `src/` | الواجهة (React + Vite) |
| `src/pages/` | صفحات المنصّة: الحضور، الموارد البشرية، الرواتب، الطلبات، ملف الموظف… |
| `src/components/` | مكوّنات الواجهة مرتّبة حسب القسم (`hr/`، `payroll/`، `attendance/`…) |
| `src/lib/` | منطق الأعمال في العميل: قواعد نظام العمل، الإجازات، الرواتب، الهيكل |
| `src/api/` | طبقة الوصول إلى الخادم — الواجهة لا تصل إلى البيانات إلا عبرها |
| `base44/` | الخادم: الجداول (`entities`)، الدوال (`functions`)، القواعد المشتركة (`shared`)، والمهام المجدولة (`workflows`) |
| `scripts/` | الاختبارات (`test-*.mjs`) وأدوات البناء |
| `docs/` | ملاحظات تصميم وشروحات لقواعد نظام العمل |
| `public/` | الشعار والأيقونات |
| `CLAUDE.md` و`AGENTS.md` | قواعد العمل على الكود (للمطوّرين ولأدوات الذكاء الاصطناعي) |

ملفات الإعداد في الجذر (`vite.config.js`، `tailwind.config.js`، `postcss.config.js`، `eslint.config.js`، `jsconfig.json`، `components.json`) تبقى في مكانها لأن الأدوات تقرؤها منه.

## التشغيل محلياً

```bash
npm install
npm run dev        # الواجهة فقط
```

ثم افتح `#/preview` لنسخة تجريبية ببيانات وهمية.

لربط الواجهة بالخادم المستضاف أنشئ `.env.local` (لا يُرفع إلى المستودع):

```bash
VITE_BASE44_APP_ID=...
VITE_BASE44_APP_BASE_URL=...
```

## الفحص قبل الرفع

```bash
npm run lint       # فحص الكود
npm test           # حواجز الطبقات وتطابق العميل والخادم والاختبارات
npm run build      # بناء النسخة النهائية
```

## قواعد ثابتة

- الواجهة عربية أولاً ومن اليمين إلى اليسار.
- بيانات كل منشأة كتلة واحدة لكل `companyId`، ولا تُكتب إلا عبر `updateCompany`.
- كل قاعدة تمنع إجراءً تذكر سبب المنع، وكل رقم على الشاشة مشتقّ لا مكتوب يدوياً.
- كل قاعدة في العميل لها نظيرها في الخادم.
